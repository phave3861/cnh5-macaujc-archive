# cnh5-macaujc-archive

## 项目简介

本仓库用于归档和发布多个独立的 HTML 页面。这些页面以静态文件形式存放，不依赖后端服务，可直接通过浏览器打开查看。仓库内容主要涉及信息展示、文档整理或特定主题的页面集合，不针对任何单个域名或具体网站。

## 目录结构

```
cnh5-macaujc-archive/
├── README.md          # 本文件
├── index.html         # 主入口页面（如有）
├── pages/             # 存放各独立 HTML 页面
│   ├── example1.html
│   ├── example2.html
│   └── ...
└── assets/            # 页面所需的资源文件（CSS、JS、图片等）
    ├── css/
    ├── js/
    └── images/
```

- `pages/`：主要页面归档目录，每个 .html 文件为一个独立页面。
- `assets/`：存放页面引用的静态资源，按类型分类。

## 页面归档说明

- 所有页面均为纯 HTML + CSS + JavaScript 实现，无后端依赖。
- 页面内容可能涉及历史记录、参考文档或信息汇总，仅供存档与查阅。
- 页面之间相互独立，不保证存在导航链接或跳转关系。
- 归档文件可能不定期更新或补充，但不对内容时效性做特别保证。

## 使用方式

1. 克隆或下载本仓库到本地。
2. 使用任意浏览器直接打开 `index.html` 或 `pages/` 目录下的页面文件。
3. 如需部署到静态托管服务（如 GitHub Pages、Netlify 等），可直接将仓库根目录作为站点根目录。
